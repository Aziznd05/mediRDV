# MédiRDV — Plateforme de gestion des rendez-vous médicaux

**Clinique Les Baobabs · Dakar, Sénégal** · AO-CLB-2026-01

## Description

MédiRDV centralise la prise de rendez-vous des 9 spécialités de la clinique, fiabilise les plannings et fournit un tableau de bord analytique pour piloter l'activité (réduction des absences, meilleure répartition de la demande).
